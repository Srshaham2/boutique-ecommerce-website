# BieLux logo

Save the BieLux wordmark image (the calligraphic "BieLux" + orchid you provided)
into this folder as:

    public/bielux-logo.png

The header and footer reference `/bielux-logo.png` automatically. Until that file
exists, the site shows a graceful fallback: the brand name rendered in the
matching calligraphic script font (Pinyon Script).

Recommended export: transparent PNG, ~600px tall, black artwork on transparent
background so it sits cleanly on the white header.
